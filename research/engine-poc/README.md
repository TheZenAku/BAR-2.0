# Engine POCs (M0)

Equivalent POCs for **Three.js**, **Babylon.js** and **PlayCanvas** (engine-only, no editor). Frozen research artifact:
it is not part of the product and it is excluded from the main lint/CI. Results and analysis are in [results/RESULTS.md](results/RESULTS.md);
the decision is in [ADR-0001](../../docs/decisions/ADR-0001-engine.md).

## What is identical across the three POCs

- **Assets**: generated by `tools/gen-assets.mjs` (100% original, no external license): greybox bar GLB
  (119 nodes, ~8.1k tris, shared meshes for repeated props, 7 PBR materials incl. one emissive) and a skinned
  avatar GLB (18 joints, ~3.7k tris, 4 materials/primitives, clips Idle/Walk/Sit).
- **Simulation** (`src/common/sim.ts`): Rapier `0.21.0` world with box colliders from `bar-colliders.json`,
  kinematic character controller per avatar, seeded bot wandering, third-person camera with ray-cast collision.
- **Runner** (`src/common/run.ts`): input (WASD + drag orbit + wheel), HUD, metrics and benchmark protocol.
- **Lighting setup**: hemisphere + 1 directional with 2048² PCF shadows + 4 point lights, exp² fog, ACES tone mapping,
  MSAA, pixel ratio 1. Light units differ per engine; intensities were calibrated by eye only.

Engine-specific code (`src/<engine>/main.ts`) does loading, cloning, animation cross-fade (0.2 s), rendering and stats.

## Run

```bash
npm ci
npx playwright install firefox     # optional; Chromium runs use the installed Edge channel
npm run dev                         # http://localhost:5173/three.html | babylon.html | playcanvas.html  (?n=16&shadows=1)
npm run build                       # per-engine production builds + results/bundle-sizes.json
node tools/bench.mjs --browser=msedge --reps=3 [--uncapped]
node tools/bench.mjs --browser=firefox --reps=2
```

Benchmark protocol: 1280×720, 3 s warm-up, 10 s measurement, cases n = 1/16/48 avatars with shadows and 48 without.
`frameMs` = interval between frame starts (includes vsync wait unless `--uncapped`); `cpuMs` = main-thread time
from frame start to end of the engine's render call (GPU work is asynchronous and not included).
