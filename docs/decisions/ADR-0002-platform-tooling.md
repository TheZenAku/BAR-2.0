# ADR-0002 — Plataforma, ferramentas e stack de servidor

- Status: **Aceita** para os itens marcados como _adotado_; itens _provisório_ serão validados no marco indicado.
- Data: 2026-10-26 (M0).

Node 24 e 26 verificados no GitHub Actions (run 40389749929, 2026-10-26)                                                                                                                                                                                                                                    |
